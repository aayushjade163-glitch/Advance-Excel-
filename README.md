# Advanced Microsoft Excel – Learning Resources & Practice

This folder contains my Advanced Microsoft Excel learning materials, classroom teaching files, practical assignments, exercises, and project work completed as part of the Data Science & Data Analytics course at IT Vedant.

The purpose is to maintain an organised backup of all Excel-related learning resources and document my practical progress.

- Conditional formatting
- Data validation

- Pivot Tables and Pivot Charts
- Charts and data visualization
- Interactive dashboards
- Practical assignments and business analysis tasks
